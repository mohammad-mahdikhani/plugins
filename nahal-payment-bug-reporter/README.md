# گزارشگر خطای پرداخت نهال

افزونه وردپرس / ووکامرس برای صفحات پرداخت [nahal.website](https://nahal.website).

در کل سایت فقط **یک** دکمه شناور «گزارش خطا» دیده می‌شود (نه کنار سبد یا دکمه خرید). فقط کاربر لاگین‌شده با موبایل تأییدشده می‌تواند گزارش بفرستد. اسکرین و پرامپت ایجنت فقط برای مدیر ارسال می‌شود. اگر المان حیاتی مسیر خرید لود نشود، گزارش فهرست‌شده همراه مشخصات تماس برای مدیر می‌رود.

در پیشخوان وردپرس نوتیف و فهرست خطاها هست؛ صفحه «هفتگی / ماهانه» نشان می‌دهد چه خطاهایی آمده و کدام رفع شده‌اند.

روی هاست ایران `api.telegram.org` فیلتر است؛ Worker خودتان (`telegram-proxy-worker.js`) را در تنظیمات به‌عنوان پروکسی API بگذارید. از پروکسی عمومی دیگران استفاده نکنید.

## نصب

فایل آماده: [`../dist/nahal-payment-bug-reporter.zip`](../dist/nahal-payment-bug-reporter.zip)

در پیشخوان: **افزونه‌ها ← افزودن ← بارگذاری افزونه**. ووکامرس باید فعال باشد.

راهنما: `INSTALL-FA.txt` و `GUIDE-FA.txt`

## تست بدون وردپرس

```bash
php nahal-payment-bug-reporter/tests/run.php
```

پیش‌نمایش رابط صفحه پرداخت:

```bash
php -S 127.0.0.1:8765 -t nahal-payment-bug-reporter
```

سپس `http://127.0.0.1:8765/tests/preview-checkout.html` را باز کنید.

پیش‌نمایش پیشخوان (نوتیف، فهرست، گزارش هفتگی/ماهانه):

`http://127.0.0.1:8765/tests/preview-admin.php`
