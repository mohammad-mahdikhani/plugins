دکمه گزارش خطا در صفحات و فیلدهای پرداخت؛ ثبت کدهای لودنشده، اسکرین‌شات و ارسال برای مدیر.

== Description ==

برای nahal.website. روی تسویه ووکامرس و باکس پرداخت یک دکمه گزارش می‌گذارد. کاربر شرح خطا را می‌نویسد. افزونه فایل‌های لودنشده و اسکرین همان صفحه را جمع می‌کند، ZIP می‌دهد و برای مدیر ایمیل می‌کند.

== Installation ==

1. ZIP را از افزونه‌ها بارگذاری کنید.
2. فعال کنید.
3. از منوی «خطای پرداخت» ایمیل مدیر را بگذارید.
