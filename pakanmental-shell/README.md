# Pakan Mental Product Shell (Elementor templates)

یک قالب المنتوری ثابت برای هر نوع صفحه — قابل ویرایش با دکمهٔ «ویرایش با المنتور»، بدون بوم جدا برای هر SKU.

| بخش | سند پیش‌فرض | ویرایش |
| --- | --- | --- |
| هدر | کتابخانهٔ المنتور `124` | پیشخوان → قالب پاکان |
| فوتر | `125` | همین |
| تک محصول | قالب کتابخانهٔ `PM Single Product` | همین |
| آرشیو محصول | `PM Product Archive` | همین |
| فروشگاه | صفحه `15` | همین |
| بلاگ / مجله | صفحه `20` | همین |

## فایل نصب ویندوز

`artifacts/PakanMental-Setup.exe` را روی ویندوز اجرا کنید. فایل `pakanmental-shell.zip` روی دسکتاپ در پوشه `PakanMental` قرار می‌گیرد. همان zip را از پیشخوان وردپرس، مسیر افزونه‌ها ← افزودن ← بارگذاری افزونه، نصب کنید.

ساخت دوباره: `python3 scripts/pm_deploy/build_windows_setup.py`

## نصب / به‌روزرسانی

1. افزونه را فعال نگه دارید.
2. پیشخوان → **قالب پاکان** → «ساخت / تعمیر قالب‌های تک‌محصول و آرشیو».
3. روی هر ردیف **ویرایش با المنتور** بزنید.

محصول جدید همان قالب تک‌محصول را می‌گیرد. ویژگی‌های ووکامرس در خلاصه به صورت خانه‌های مربعی سبز نشان داده می‌شوند.
