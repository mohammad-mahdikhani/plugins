# Pakan Mental Product Shell

قالب ثابت صفحهٔ محصول و دسته برای ووکامرس. محصول جدید دیگر روی هدر پیش‌فرض Hello Elementor باز نمی‌شود.

## نصب (یک‌بار)

1. فایل `artifacts/pakanmental-shell.zip` را در وردپرس بارگذاری کنید: **افزونه‌ها → افزودن → بارگذاری افزونه**.
2. افزونهٔ **Pakan Mental Product Shell** را فعال کنید.
3. افزونهٔ فعلی `pakanmental-home` 1.1.2 را نگه دارید (استایل و اسکریپت از همان خوانده می‌شود).

بعد از فعال‌سازی، هر محصول بدون بوم المنتور (از جمله پیش‌نویس‌ها) هدر/فوتر پاکان و ویژگی‌ها کنار تصویر را می‌گیرد. محصولاتی که از قبل بوم المنتور دارند دست نمی‌خورند.
