## نقشهٔ پیاده‌سازی در WordPress + Elementor + WooCommerce

| بلوک وایرفریم | ویجت / الگوی Elementor |
|---------------|-------------------------|
| هدر | Theme Builder → Header: لوگو Image وسط، Nav Menu چپ/راست، آیکن جستجو + سبد WooCommerce |
| هیرو | Slider / Carousel Pro یا Loop Carousel + دستی یا داینامیک «محصولات جدید» |
| دسته‌بندی | Icon Box یا تصویر دایره‌ای — لینک به `product_cat` |
| ردیف‌های محصول | **Products** یا **Loop Grid** با فیلتر دسته؛ برای کاروسل: **Nested Carousel** / Swiper |
| پرفروش | ویجت Products → Order by: popularity |
| ترند | Order by: date یا تگ محصول «ترند» |
| مجله | Posts widget → ۳ پست آخر |
| فوتر | Theme Builder → Footer |

### وقتی هنوز محصول ندارید

- در وایرفریم، کارت‌ها عمداً placeholder هستند.
- در Elementor می‌توانید **Placeholder تصویر** و متن «به‌زودی» بگذارید، یا اسلایدر را فقط روی **دسته‌بندی‌ها** ببندید تا بعد از import محصول، همان Loopها پر شوند.

### دسته‌های پیشنهادی WooCommerce

1. `board-games` — بردگیم  
2. `puzzles` — پازل  
3. `action-figures` — اکشن فیگور  
4. `card-games` — کارتی  
5. `mental-games` — بازی منتالی (آینده)  
6. `accessories` — لوازم جانبی  

## تایپوگرافی

- **لاتین/اعداد قیمت:** همان خانواده برای یکدستی

## اصول UI

- گوشه‌های گرد (۱۶px کارت، دکمه pill) هم‌خوان با لوگوی حبابی
- فضای سفید زیاد؛ هدر مینیمال بدون بنر اضافه
- بخش‌های یک‌درمیان پس‌زمینهٔ `--pm-cream-100` برای تفکیک ردیف‌ها

## پیش‌نمایش محلی

از ریشهٔ پروژه:

```bash
cd design/wireframe && python3 -m http.server 8765
```

سپس در مرورگر: `http://localhost:8765`

## گام‌های بعدی (در صورت تمایل)

1. ساخت Header/Footer در Elementor Theme Builder مطابق وایرفریم  
2. تعریف Global Colors از `tokens.css`  
3. یک Template صفحهٔ اصلی و انتشار پس از اولین محصولات
