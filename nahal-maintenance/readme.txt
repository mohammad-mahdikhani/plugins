صفحه تعمیر شیشه‌ای و سه‌بعدی برای زمانی که سایت نهال در حال به‌روزرسانی است.

== Description ==

برای nahal.website. با روشن‌کردن حالت تعمیر، بازدیدکننده یک صحنه سه‌بعدی با مکعب‌های شیشه‌ای می‌بیند. مدیر وارد پیشخوان می‌شود. متن، تلفن و زمان برگشت از تنظیمات قابل تغییر است.

== Installation ==

1. ZIP را از افزونه‌ها بارگذاری کنید.
2. فعال کنید.
3. از منوی «صفحه تعمیر» متن را تنظیم و حالت را روشن کنید.
