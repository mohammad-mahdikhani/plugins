SCHEMA NOVA

هوش‌اسکیما آمادهٔ نصب روی وردپرس است

فایل ZIP استاندارد وردپرس را از وب بیکری دانلود کنید، از افزونه‌ها → افزودن → بارگذاری افزونه نصب کنید. روی هر قالبی کار می‌کند.

اسکیمای گوگل

گراف JSON-LD متصل برای مقاله، محصول، نان‌ریزه، ویدئو، رویداد و فروشگاه.

تایتل هوشمند

اتصال به API آنالیتیکس یا سرچ کنسول و بازنویسی تایتل/متا بر اساس اینتنت جستجو.

نصب در سه قدم

دانلود ZIP، آپلود در وردپرس، پر کردن هویت سازمان در منوی هوش‌اسکیما.

بعد از دانلود

  1. در پیشخوان وردپرس: افزونه‌ها → افزودن → بارگذاری افزونه → انتخاب ZIP.
  2. افزونه را فعال کنید. منوی «هوش‌اسکیما» ظاهر می‌شود.
  3. هویت سازمان را پر کنید، سپس در «منبع داده» API آنالیتیکس را وصل کنید.
