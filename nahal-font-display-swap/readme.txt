اجبار font-display: swap برای فونت‌های قالب، المنتور و گوگل‌فونت.

== Description ==

نوع بارگذاری فونت را در المنتور، قالب و هر @font-face دیگر به swap تبدیل می‌کند تا متن هنگام لود فونت مخفی نماند.

== Installation ==

ZIP را از افزونه‌ها بارگذاری و فعال کنید. از ابزارها ← فونت Display Swap فایل‌های CSS را هم تبدیل کنید.
