اجبار font-display: swap و بستن اسکرول افقی قالب/المنتور.

== Description ==

نوع بارگذاری فونت را در المنتور، قالب و هر @font-face دیگر به swap تبدیل می‌کند تا متن هنگام لود فونت مخفی نماند. اسکرول افقی سکشن‌های کشیدهٔ المنتور را هم می‌بندد.

== Installation ==

ZIP را از افزونه‌ها بارگذاری و فعال کنید. از ابزارها ← فونت Display Swap فایل‌های CSS را هم تبدیل کنید.
