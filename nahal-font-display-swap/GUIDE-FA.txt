چرا
---
اگر فونت با font-display: auto یا block لود شود، متن تا آماده شدن
فایل فونت دیده نمی‌شود (FOIT) و PageSpeed هشدار
«Ensure text remains visible during webfont load» می‌دهد.
swap متن را با فونت جایگزین نشان می‌دهد تا فونت اصلی برسد.

چه چیزی تبدیل می‌شود
--------------------
* گوگل‌فونت (css و css2) حتی اگر display=auto/block باشد
* Bunny Fonts و Fontshare
* @font-face داخل HTML و CSS قالب
* فونت گوگل المنتور (گزینه Google Fonts Load قفل روی swap)
* فونت سفارشی Elementor Pro
* آیکون‌فونت و فونت محلی که @font-face دارند

چه چیزی دست نمی‌خورد
--------------------
* فایل باینری فونت روی fonts.gstatic.com
* display معمولی المان‌ها (flex/block روی دکمه‌ها)
* ادمین وردپرس (به‌جز قفل تنظیم المنتور)

اسکرول افقی
------------
سکشن کشیدهٔ المنتور با width:100vw روی موبایل صفحه را به چپ/راست
می‌کشد. افزونه overflow-x را می‌بندد و عرض سکشن را 100٪ می‌کند.


ابزار فایل
----------
از «ابزارها ← فونت Display Swap» CSS کش المنتور و در صورت تمایل
CSS قالب را روی دیسک هم عوض می‌کند. برای قالب یک فایل
.nfds-bak کنارش ساخته می‌شود.
