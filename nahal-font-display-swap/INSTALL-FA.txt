راهنمای نصب افزونه فونت Display Swap نهال v1.0.1

============================================================

روی nahal.website (و هر سایت وردپرس دیگر) نوع بارگذاری فونت
را اجباراً روی font-display: swap می‌گذارد تا متن صفحه تا آمدن
فونت قالب / المنتور / گوگل‌فونت مخفی نماند. اسکرول افقی سایت را هم می‌بندد.

نیازمندی‌ها
-----------
* وردپرس 5.8 یا بالاتر
* PHP 7.4 یا بالاتر
* المنتور لازم نیست؛ اگر باشد تنظیم Google Fonts Load قفل می‌شود روی Swap

نصب
----
1. ZIP افزونه را دانلود کنید (نه ZIP کل مخزن):
   dist/nahal-font-display-swap.zip

2. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه
   همان ZIP را نصب و فعال کنید.

   ساختار صحیح:
     wp-content/plugins/nahal-font-display-swap/nahal-font-display-swap.php

3. از لحظه فعال‌سازی، لینک گوگل‌فونت و @font-face داخل HTML
   به swap تبدیل می‌شود. برای فایل‌های CSS کش المنتور و قالب:

   ابزارها ← فونت Display Swap ← تبدیل به font-display: swap

4. اگر المنتور دارید: المنتور ← ابزارها ← بازسازی CSS و داده
   بعد دوباره دکمه تبدیل را بزنید.

بدون وردپرس (پوشه قالب)
----------------------
php nahal-font-display-swap/bin/convert.php /path/to/theme
