# plugins

## هوش‌اسکیما | Schema Nova

وردپرس‌پلاگین برای اسکیمای JSON-LD مطابق [مستندات گوگل](https://developers.google.com/search/docs/appearance/structured-data/search-gallery) و گزارش [Rich results](https://support.google.com/webmasters/answer/7552505)، به‌علاوه به‌روزرسانی هوشمند تایتل و متا بر اساس اینتنت جستجو.

نصب: پوشهٔ `schema-nova` را در `wp-content/plugins/` بگذارید و فعال کنید.

جزئیات کامل در [`schema-nova/README.md`](schema-nova/README.md).
