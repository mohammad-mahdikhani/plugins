# plugins

افزونه‌های وردپرس / ووکامرس.

## گزارشگر خطای پرداخت نهال

`nahal-payment-bug-reporter` — فقط یک دکمه شناور «گزارش خطا» روی nahal.website. فقط کاربر لاگین‌شده با موبایل تأییدشده می‌تواند گزارش بفرستد. در پیشخوان نوتیف و فهرست خطاها هست؛ گزارش هفتگی و ماهانه نشان می‌دهد چه خطاهایی آمده و کدام رفع شده‌اند.

فایل نصب: `dist/nahal-payment-bug-reporter.zip`
