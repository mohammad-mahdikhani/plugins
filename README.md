# plugins

افزونه‌های وردپرس / ووکامرس.

## گزارشگر خطای پرداخت نهال

`nahal-payment-bug-reporter` — دکمه گزارش خطا روی کل سایت nahal.website با تمرکز روی سبد خرید، دکمه خرید، فروشگاه، محصول و درگاه. گزارش شامل دستگاه، نام، فامیلی، موبایل لاگین و خریدهای قبلی است. در پیشخوان نوتیف و فهرست خطاها هست؛ گزارش هفتگی و ماهانه نشان می‌دهد چه خطاهایی آمده و کدام رفع شده‌اند.

فایل نصب: `dist/nahal-payment-bug-reporter.zip`
