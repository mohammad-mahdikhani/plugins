# Elinor Beauties Homepage

قالب صفحه اصلی فروشگاه **الینور استور** با الهام از لندینگ Beauties و رنگ اصلی `#341555`.

## نصب روی وردپرس (elinorstore.com)

1. پوشه `elinor-beauties-homepage` را ZIP کنید.
2. در پیشخوان: **افزونه‌ها → افزودن → بارگذاری افزونه** و فعال‌سازی.
3. از **تنظیمات → صفحه اصلی Beauties** مطمئن شوید گزینه فعال است.
4. در **تنظیمات → خواندن**، یک صفحه (مثلاً «خانه») را به‌عنوان صفحه اصلی انتخاب کنید.

پلاگین فقط روی `is_front_page()` قالب سفارشی را بارگذاری می‌کند و محصولات را از WooCommerce می‌خواند.

## غیرفعال‌سازی

تیک «نمایش قالب سفارشی» را بردارید تا Woodmart دوباره قالب قبلی را نشان دهد.
