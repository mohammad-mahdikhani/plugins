به‌روزرسانی یکجای قیمت محصولات ووکامرس با آپلود لیست قیمت اکسل یا PDF.

== Description ==

وقتی لیست قیمت جدیدی را به‌صورت Excel یا PDF آپلود می‌کنید، قیمت همه محصولات منطبق با آن لیست عوض می‌شود.

* پشتیبانی از xlsx، xls، csv و PDF متنی
* تشخیص خودکار ستون‌ها (کد کالا، قیمت، قیمت ویژه، موجودی)
* پیش‌نمایش قبل از اعمال
* تاریخچه و بازگشت به قیمت قبلی
* خروجی اکسل از قیمت‌های فعلی فروشگاه

== Installation ==

1. پوشه افزونه را در wp-content/plugins/ کپی کنید.
2. افزونه را فعال کنید (ووکامرس باید فعال باشد).
3. منوی «لیست قیمت» را باز کنید و فایل را آپلود نمایید.
