# لیست قیمت حسابدار (Hesabdar Price List)

افزونه وردپرس / ووکامرس برای به‌روزرسانی یکجای قیمت محصولات با آپلود فایل اکسل یا PDF.

وقتی لیست قیمت جدید را آپلود می‌کنید، قیمت همه کالاهای منطبق با آن لیست عوض می‌شود.

## نصب

فایل آماده نصب: [`../dist/hesabdar-price-list.zip`](../dist/hesabdar-price-list.zip)

در پیشخوان وردپرس: **افزونه‌ها ← افزودن ← بارگذاری افزونه** و همین ZIP را انتخاب کنید. ووکامرس باید فعال باشد.

راهنمای فارسی: `INSTALL-FA.txt` و `GUIDE-FA.txt`

## تست بدون وردپرس

```bash
php hesabdar-price-list/tests/run.php
```
