کیت تست / استودیو دفترچی (1.1.7-test)
======================================

نسخه بدون اشتراک — محدودیت ۷ روز و خرید لایسنس اعمال نمی‌شود.

۱) Daftarchi-Test.zip را Extract کنید.
۲) Run-Test.bat را بزنید (یا Install-To-E.bat برای E:\Daftarchi\Test)
۳) ورود: 09120000000 / daftarchi
۴) بالای برنامه باید «فروشگاه تست» و وضعیت لایسنس «نسخه استودیو» ببینید.

چطور بدون اشتراک کار می‌کند:
- فایل studio-unlock.txt کنار exe
- متغیر DAFTARCHI_UNLOCK=1 در Run-Test.bat
- لایسنس ۵۰ ساله از پیش در data (برای exe قدیمی‌تر)

داده فقط داخل پوشه data همین کیت است؛ پاک کردن data = شروع از نو (دوباره preset اعمال می‌شود).

برای آخرین اصلاحات (موجودی، Woo، preset) exe را از سورس daftarchi/
با Build-Exe-1.1.7.bat بسازید و جایگزین Daftarchi.exe کنید.
