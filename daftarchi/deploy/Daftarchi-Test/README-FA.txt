کیت تست دفترچی (1.1.7-test)
============================

برای آزمایش روی PC خودتان — جدا از فروش واقعی.

۱) Daftarchi-Test.zip را Extract کنید.
۲) Run-Test.bat را بزنید (یا Install-To-E.bat برای E:\Daftarchi\Test)
۳) ورود: 09120000000 / daftarchi
۴) بالای برنامه و روی فاکتور باید «فروشگاه تست» ببینید.

داده فقط داخل پوشه data همین کیت است؛ پاک کردن data = شروع از نو.

برای آخرین اصلاحات (موجودی، preset، 1.1.7-test) exe را از سورس
daftarchi/ با Build-Exe-1.1.7.bat بسازید و جایگزین Daftarchi.exe کنید.
