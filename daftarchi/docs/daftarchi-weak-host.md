# هاست ضعیف (موازی) — بدون شکستن LAN

این سند مسیر **آینده** است. تا وقتی منتشر نشود، مشتری فقط **LAN مغازه** را طبق [daftarchi-webapp.md](./daftarchi-webapp.md) استفاده کند.

## اصل

```
مسیر A (اصلی، همیشه)          مسیر B (موازی، اختیاری)
PC سرور مغازه                  هاست مشترک / ارزان
0.0.0.0:8080                   nginx + HTTPS + app.py
Wi‑Fi LAN                      اینترنت / 4G
Start-Daftarchi.bat            آپلود یا سرویس روی هاست
```

- **LAN نشکسته می‌شود:** پیش‌فرض `DAFTARCHI_BIND=0.0.0.0`، `DAFTARCHI_LAN_CORS=1`، چاپ و کارت‌خوان روی PC محلی.
- **هاست جای LAN نیست:** مشتری می‌تواند فقط A را داشته باشد؛ B برای کسی که از راه دور به همان UI نیاز دارد.
- **یک مغازه، یک DB در هر مسیر:** یا داده روی PC (A) یا روی هاست (B) — بدون ادعای سینک دوطرفهٔ خودکار در نسخهٔ ضعیف.

## چه چیزی مشترک است

| بخش | LAN | هاست ضعیف |
|-----|-----|------------|
| UI | `app.js` + PWA | همان |
| API | `/api/*` | همان |
| ورود | موبایل/رمز | همان (+ Webakery اختیاری) |
| کلاینت | مرورگر | مرورگر |

## چه چیزی روی هاست ضعیف محدود است (عمدی)

- منابع کم (CPU/RAM/shared hosting).
- بدون تضمین چاپ/کارت‌خوان از راه دور — آن‌ها روی **PC LAN** می‌مانند.
- مناسب: موجودی، قیمت، گزارش، نظارت از موبایل بیرون مغازه — نه جایگزین صندوق سریع LAN.

## پیاده‌سازی (وقتی شروع شد)

- همان `app.py` پشت reverse proxy؛ `DAFTARCHI_DATA` روی دیسک هاست.
- **هیچ تغییری** که `127.0.0.1`-only یا وابستگی اجباری به دامنه برای نصب Windows ایجاد کند، پذیرفته نیست.
- کارت ورود «سرور مرکزی» همچنان برای **آدرس LAN** است؛ آدرس هاست فقط URL دیگر در همان مرورگر.
