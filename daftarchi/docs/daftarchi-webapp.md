# دفترچی برای مشتری — وب‌اپ (داده روی سرور فروشگاه)

مشتریان دفترچی می‌توانند **مثل یک سایت** کار کنند: از **موبایل، لپ‌تاپ یا تبلت** مرورگر باز می‌شود، با **موبایل/جیمیل و رمز** وارد می‌شوند، و **موجودی و قیمت همیشه از همان سرور** خوانده می‌شود — نه از کپی جدا روی هر لپ‌تاپ.

این راهنما برای **نسخه مشتری** (`Daftarchi-Customer-setup.exe`) است؛ Owner محمد جداست.

## چه چیزی می‌گیرید

| حالت | چه دستگاهی لازم است | داده کجاست |
|------|---------------------|------------|
| **فقط یک PC صندوق** | همان PC + مرورگر | پوشه `data` روی همان PC |
| **وب‌اپ فروشگاه (پیشنهادی)** | **یک PC همیشه روشن** = سرور + هر تعداد مرورگر | **فقط روی PC سرور** (`data/daftarchi.db`) |
| **PWA روی موبایل** | همان آدرس سرور در Chrome/Safari → نصب روی صفحهٔ اصلی | باز هم روی سرور |

روی حالت وب‌اپ:

- تغییر **قیمت** یا **موجودی** از موبایل مدیر → همان لحظه برای صندوق PC هم همان عدد است.
- فروش از صندوق → موجودی برای همهٔ کلاینت‌ها یکی است.
- نیازی به کپی پوشه `data` بین لپ‌تاپ‌ها نیست.

## معماری ساده

```
┌─────────────────────────────────────────┐
│  PC سرور فروشگاه (همیشه روشن)          │
│  Start-Daftarchi.bat                    │
│  app.py + SQLite (data/daftarchi.db)    │
│  پورت 8080 — 0.0.0.0 (شبکه محلی)       │
└──────────────────┬──────────────────────┘
                   │ همان Wi‑Fi / LAN
     ┌─────────────┼─────────────┐
     ▼             ▼             ▼
  موبایل        لپ‌تاپ انبار   PC صندوق ۲
  (مرورگر/PWA)  (مرورگر)       (مرورگر یا نصب محلی)
```

- **رابط:** صفحهٔ وب (همان UI دفترچی در مرورگر).
- **محاسبه و ذخیره:** روی PC سرور؛ کلاینت فقط درخواست `/api/*` می‌فرستد.
- **ورود:** شماره موبایل `09…` یا جیمیل + رمز (حداقل ۶ کاراکتر).

## راه‌اندازی گام‌به‌گام (مشتری)

### ۱) انتخاب «سرور فروشگاه»

روی **یک** کامپیوتر ثابت (معمولاً PC اصلی مغازه):

1. نصب: [Daftarchi-Customer-setup.exe](https://github.com/mohammad-mahdikhani/plugins/raw/cursor/instant-woo-pos-receipt-3e51/daftarchi/deploy/Daftarchi-Customer-setup.exe) (پایتون همراه است).
2. `Start-Daftarchi.bat` را بزنید و **پنجره را نبندید** (یا بعداً سرویس/اجرای خودکار بگذارید).
3. در خروجی کنسول خط **`Daftarchi LAN:`** را ببینید، مثلاً `http://192.168.1.50:8080/`.
4. در ویندوز برای IP: `ipconfig` → آدرس IPv4 همان شبکه.

### ۲) اولین ورود و امنیت

1. باز کردن `http://127.0.0.1:8080/` روی همان PC.
2. ورود اول پیش‌فرض: `09120000000` / `daftarchi` — **حتماً رمز عوض شود**.
3. نام فروشگاه و تنظیمات را از داخل برنامه پر کنید.

### ۳) موبایل و لپ‌تاپ دیگر (بدون نصب دفترچی)

**روش الف — فقط مرورگر (ساده‌ترین)**

1. موبایل به **همان Wi‑Fi مغازه** وصل شود.
2. در Chrome/Safari آدرس LAN را بزنید: `http://192.168.1.50:8080/`.
3. با همان موبایل/رمز مدیر (یا کاربر مجاز) وارد شوید.
4. از بخش **کالا** موجودی و قیمت را ببینید یا ویرایش کنید؛ صندوق همان اعداد را می‌بیند.

**روش ب — از یک نصب دیگر فقط برای لینک سرور**

اگر روی لپ‌تاپ دوم هم دفترچی نصب است، لازم نیست دو `data` جدا داشته باشید:

1. صفحهٔ **ورود** → بخش **«سرور مرکزی (LAN)»**.
2. آدرس سرور را بدهید: `http://192.168.1.50:8080` → **اتصال به سرور**.
3. مرورگر به سرور می‌رود؛ از آن به بعد همان لینک را bookmark کنید.

### ۴) نصب روی صفحهٔ اصلی موبایل (PWA)

از **همان آدرس سرور** (نه فایل محلی):

- **Android Chrome:** منو → Install app / «نصب دفترچی».
- **iPhone Safari:** Share → Add to Home Screen.

برنامه مثل اپ باز می‌شود؛ داده هنوز روی **همان PC سرور** است. اگر صفحه قدیمی بود: کش را پاک کنید یا **Ctrl+Shift+R** روی PC.

### ۵) فایروال

روی PC سرور در ویندوز، پورت **8080** برای شبکهٔ **Private** باز باشد.

## ورود از بیرون مغازه (اینترنت)

نسخهٔ فعلی برای **شبکهٔ محلی (LAN/Wi‑Fi)** آماده است. دسترسی از اینترنت خانگی/4G به IP مغازه معمولاً بدون **پورت‌فوروارد یا VPN** ممکن نیست.

برای دسترسی از راه دور امن، گزینه‌های رایج:

- VPN به شبکهٔ مغازه، بعد همان آدرس LAN.
- یا آینده: قرار دادن `app.py` پشت **nginx + HTTPS** روی هاست (یک دامنه ثابت برای کل تیم).

هویت ورود بین نصب‌های مختلف می‌تواند با **Webakery** (`daftarchi-auth.php`) یکسان شود؛ **فایل حسابداری فروش** همچنان روی سرور همان فروشگاه می‌ماند.

## مقایسه با «هر لپ‌تاپ یک نصب جدا»

| | هر PC نصب جدا | وب‌اپ (یک سرور) |
|---|----------------|------------------|
| موجودی/قیمت | فقط روی همان PC | **یک منبع برای همه** |
| موبایل مدیر | ندارد / ناسازگار | **مرورگر کافی است** |
| پشتیبان‌گیری | چند پوشه `data` | **یک پوشه `data` روی سرور** |
| PC صندوق | نصب کامل OK | نصب محلی **یا** فقط مرورگر |

## محدودیت‌های فعلی (صادقانه)

- **یک سرور = یک فروشگاه** (یک `daftarchi.db`). چند مغازه روی یک DB هنوز نیست.
- **سرور باید روشن باشد**؛ موبایل خودش دیتابیس کامل نگه نمی‌دارد.
- **چاپ و کارت‌خوان** معمولاً به PC وصل فیزیکی همان محل وابسته است؛ موبایل برای موجودی، قیمت، گزارش و نظارت عالی است.

## جمع‌بندی برای مشتری

**وب‌اپ دفترچی = یک PC سرور همیشه روشن + لینک `http://IP:8080` روی موبایل و بقیه دستگاه‌ها + ورود موبایل/رمز.**  
موجودی و قیمت از همان سرور خوانده می‌شود؛ هر دستگاه فقط مرورگر (یا PWA) می‌خواهد، نه کپی دیتابیس جدا.
