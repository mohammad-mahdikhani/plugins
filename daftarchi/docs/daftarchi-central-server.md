# سرور مرکزی LAN — راهنمای مشتری

این سند تکمیل [daftarchi-webapp.md](./daftarchi-webapp.md) است و جزئیات فنی ورود «اتصال به سرور» را توضیح می‌دهد.

## هدف

یک `daftarchi.db` روی **یک PC**؛ بقیه دستگاه‌ها فقط **مرورگر** — بدون کپی پوشه `data`.

## راه‌اندازی سرور

1. نصب مشتری روی PC ثابت.
2. `Start-Daftarchi.bat` — برنامه روی `0.0.0.0:8080` گوش می‌دهد.
3. آدرس LAN از کنسول یا `ipconfig` → مثال `http://192.168.1.10:8080/`.
4. فایروال: پورت 8080 باز.

## کلاینت (موبایل / لپ‌تاپ / PC دوم)

- **مستقیم:** همان URL در مرورگر.
- **از صفحهٔ ورود دفترچی:** بخش **سرور مرکزی (LAN)** → آدرس → **اتصال به سرور** (ذخیره در مرورگر با `daftarchi_server_url`).

ورود با همان اکانت موبایل/رمز روی **همان سرور**؛ session روی origin سرور است.

## پیاده‌سازی (۱.۱.۹۴+)

| بخش | رفتار |
|-----|--------|
| `app.py` | `DAFTARCHI_BIND=0.0.0.0` پیش‌فرض، CORS روی `/api/*` (`DAFTARCHI_LAN_CORS=1`) |
| `app.js` | کارت «سرور مرکزی» در ورود، ریدایرکت به سرور |
| داده | فقط روی سرور |

خاموش کردن CORS: متغیر محیط `DAFTARCHI_LAN_CORS=0` (فقط در صورت نیاز).

## آنچه نیست

- چند فروشگاه جدا روی یک سرور (یک DB = یک مغازه).
- سینک خودکار بین چند سرور جدا (محصول جدا).
